## Algorithms

### World Fortune Algorithm

[World Fortune Algorithm](scripts/algorithms/world_fortune_algorithm_sample.py) is a ranking algorithm designed for community content feeds. It models a post's age as an initial "wealth" endowment and combines it with subsequent user interactions, providing a principled way to balance freshness and accumulated popularity.

The implementation contains the original model, formulas, and engineering notes behind the approach.
